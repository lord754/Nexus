Nexus Launcher
Кастомный, стильный лаунчер Minecraft Java Edition в тёмной теме для Android, созданный на движке FCL.

Возможности
Кастомный тёмный интерфейс Nexus

Встроенная загрузка из Modrinth и CurseForge

Работает на игровом движке FCL

Благодарности
Создано на основе невероятной работы сообщества с открытым исходным кодом FCL-Team, PojavLauncher и HMCL. Это неофициальный форк.
